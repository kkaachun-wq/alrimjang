# 나만의 알림장

할일과 생활 정보를 한곳에 모아 두는 모바일 웹 앱(PWA)입니다.
설치 없이 브라우저에서 열고, 안드로이드 크롬의 **홈 화면에 추가**로 앱처럼 쓸 수 있습니다.

## 항목

| 항목 | 쓰임 |
| --- | --- |
| 할일 | 마감 날짜·시간과 알림 |
| 여행 | 여행 정보 스크랩 |
| 레스토랑 | 식당·카페 기록 |
| 경제·재무 | 금융·재무 메모 |
| 골프 | 골프장·라운드 정보 |
| 쇼핑 | 살 것·가격 정보 |
| 생활 | 그 밖의 생활 정보 |

## 기능

- 7개 항목별 카드 목록, 전체 검색, 항목 필터 칩
- 카드: 제목, 내용, 링크(주소), 태그, 고정(📌), 수정, 삭제(되돌리기 가능)
- 할일: 완료 체크, 마감일·시간, 임박 순 정렬, 마감 지남/오늘/임박 색 구분
- 알림: 앱을 열어 둔 동안 브라우저 알림 (마감 시간, 30분·1시간·3시간 전 중 선택)
- 캘린더: 할일을 `.ics` 파일로 내려받아 폰 캘린더에 등록하거나 구글 캘린더에 바로 추가
- 백업: JSON 내보내기 / 불러오기(중복 없이 합치기)
- 오프라인 동작(서비스 워커 캐시), 홈 화면 설치(manifest)

## 저장 방식

모든 기록은 **이 기기 브라우저의 localStorage** 에만 저장되며 어느 서버로도 전송되지 않습니다.
따라서 브라우저 기록·사이트 데이터를 지우면 기록도 함께 사라집니다. 설정 ☰ → **JSON 백업 내보내기**로
가끔 백업해 두세요.

## 구조

```
index.html      화면
style.css       스타일
app.js          앱 로직 (저장·검색·정렬·알림·백업·캘린더)
manifest.json   PWA 설정
sw.js           서비스 워커(오프라인 캐시)
icons/          앱 아이콘
tools/make_icons.py  아이콘 생성 스크립트
```

## 배포

GitHub Pages(main 브랜치 루트)로 배포됩니다. `index.html` 을 루트에 두고 상대 경로만 사용하므로
`https://<사용자>.github.io/<저장소>/` 어디에서든 동작합니다.

## 배포 후 코드를 고칠 때

`sw.js` 맨 위의 `CACHE` 이름 숫자를 올려 주세요(`alrimjang-v2` → `alrimjang-v3`).
폰에 캐시된 예전 파일이 지워지고 새 파일로 바뀝니다. 이번 배포에서 이미 화면(문서)은
네트워크 우선, 나머지 파일은 캐시 우선 + 뒤에서 갱신으로 바꿔 두었습니다.
